一覧・ドロワーのキーボード操作を、速く、取りこぼしなく動くように作り直しました。

## 新機能

- **Ctrl + ↓ のアプリドロワーでも、青枠でアイコンを選べる**ようにしました。一覧（Ctrl + ↑）と同じく、矢印で移動して Enter で起動します。
- **Esc / Back で選択モードを抜ける**ようにしました。一覧・ドロワーもそのまま閉じます。
- 見切れているカードを選ぶと、全体が見える位置まで自動で寄せます。
- 選択枠の移動に短いスライドのアニメーションを付けました。
- アプリのアイコンを新しいデザインにしました。

## 改善

- 矢印での移動を、カードの座標ではなく行・列の並びで決めるようにしました。アニメーションの途中でも、すぐ正しい隣へ動きます。
- 動作中に押した矢印を順番にためて実行し、入力を取りこぼさないようにしました。
- Ctrl + ↑ の一覧と、ドロワーが開いて枠が出るまでを速くしました。ページ送りのあとの待ち時間も短くしています。
- スクロールの操作は、修飾キーを押しただけではなく、トラックボールが実際に動いた瞬間に始めるようにしました。修飾キーがほかのキーを兼ねていても、通常のキー入力が吸われません。

## 修正

- ページ送りのあとに行が入れ替わる、行き過ぎる問題を直しました。
- ドロワーで、背後のホーム画面のアイコンを拾って枠が飛ぶ問題を直しました。
- Enter を押さずにホームへ戻ったとき、青枠が残る問題を直しました。

## インストール手順

1. 下の `KeySwipe-v1.1.0.apk` をダウンロードして端末でインストール（提供元不明のアプリの許可が必要です）
2. アプリを起動 → 「ユーザー補助設定を開く」
3. 設定 → ユーザー補助 → **KeySwipe を ON**（フルコントロールを許可）
4. キーボードで Ctrl+↑ を押して動作確認

更新の場合は、そのまま上書きでインストールできます。設定は引き継がれます。
